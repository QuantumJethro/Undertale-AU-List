# Undertale-AU-List
This repository contains a lot of Undertale AUs and ATs that can be found in here. The list should be sorted alphabetically and is being worked on daily.
AU logic is being used here. If you don't understand what AU logic is, here it is:
You take an base AU and what is added after it, is the events of that.
As an example: Swapfell is Underswap getting fellified. Fellswap is Underfell getting swapped.
And, this can be done with all AUs and ATs.
